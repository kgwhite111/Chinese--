# 中柯智能翻译 (Chinese ↔ Kyrgyz AI Translator)

这是一个基于纯前端技术栈开发的高品质、极简、现代科技感“中文 ↔ 柯尔克孜语（Kyrgyz）”语音与文字互译网页应用。该应用无需用户登录，所有大模型 API Key 均保存在用户的浏览器本地 (`localStorage`)，极好地保护了用户隐私与开发者 API 密钥安全，非常适合托管至 Netlify 作为静态站点。

## 🌟 核心特性

- **双卡片现代极简设计**：参考了 Google 翻译与 DeepL 的交互逻辑，电脑端为优雅的左右双栏，移动端自动适配为垂直堆叠卡片。
- **无服务器/纯前端托管**：不需要任何数据库或复杂的后端，可快速一键部署到 Netlify 等静态托管平台。
- **安全的 API 密钥机制**：通过右上角的 ⚙️ 设置面板，用户可自行填入其自备的 OpenAI 兼容大模型 API 密钥、自定义模型名称和 Base URL。配置仅安全存储在本地浏览器 LocalStorage。
- **智能语言切换**：点击中间的 “⇄” 圆形旋转按钮，即可实现中英柯语对调，并自带平滑旋转动画。
- **语音录制与控制台 ASR 支持**：完美融合了 Web Audio API 与 MediaRecorder 接口。录音时自带红色发光与**双层 CSS 呼吸涟漪扩散动画**；录音结束后生成标准音频 Blob，输出于控制台，提示未来如何直接对接 Whisper。
- **文字朗读 (TTS)**：中文采用浏览器原生的 `SpeechSynthesis` 进行高清晰度女声朗读；针对浏览器原生不支持的柯尔克孜语，脚本内部详细注释了如何通过微软 Edge TTS 实现极佳的柯语朗读解决方案。
- **优雅的交互动效**：包括立即翻译按钮的优雅旋转加载 (Spinner)、文本清空 (×) 渐显动画、抽屉面板从右侧平滑滑出等。

## 🛠️ 技术栈

- **HTML5**：语义化、响应式布局结构。
- **CSS3**：采用现代 CSS 自定义变量、Flexbox 与 Grid 混合布局，支持完整 Transition 平滑过渡和 Keyframes 重度波纹、加载动画，完全抛弃了笨重的第三方框架，保证加载极速。
- **JavaScript (Vanilla JS - ES6)**：纯原生 JavaScript 驱动所有交互、Web Audio 捕获、本地存储与 OpenAI Chat Completion 协议接口请求。

## 🚀 本地开发与运行

1. 下载或克隆本项目：
   ```bash
   git clone <repository-url>
   ```
2. 直接使用任意浏览器双击打开 `index.html`，或者使用轻量级的本地 HTTP 服务器（如 VS Code 的 Live Server 插件）启动。
3. 若您在本地安装了 `netlify-cli`，也可以直接使用以下命令在本地模拟 Netlify 托管运行：
   ```bash
   netlify dev
   ```

## 🔒 隐私与安全性

- 本程序属于纯客户端静态应用。
- 我们不设置任何注册/登录流程。
- 您的 API 密钥只会安全地保存在您自己浏览器的本地存储中，所有的翻译 Fetch 请求均为您的浏览器直接发往您设置的 API 基础地址，不经过任何中转代理服务器，绝无密钥泄露风险。
